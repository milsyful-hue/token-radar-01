Token Radar ranks the pre-token protocols of a sealed DefiLlama snapshot by implied value — what a token would be worth if the protocol's record stayed as it is — and shows a reader how to farm each one. The board covers all 40 watchlist protocols plus every other pre-token protocol that passes the same test, 198 rows in all, each scored by one four-factor function of the snapshot's own figures (TVL, seven-day growth, age with no token, chain count). No protocol name is special-cased. The dashboard adds a live model sandbox, a live-token view set aside from the ranking, and the set-aside list with reasons.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
